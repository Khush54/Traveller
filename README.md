# Traveller Website 🌍

A responsive and user-friendly tourism website developed during my **Industrial Training** as a **Frontend Developer Intern** at **Excellence Technology, Mohali**.  
The website provides detailed information about **India’s historical places, religious sites, and cultural diversity**, helping users explore tourist destinations easily.

---

##  Project Overview

The **Traveller Website** is a static front-end web application designed to showcase India’s rich heritage and tourism hotspots.  
It focuses on **clean UI design, responsiveness, and easy navigation**, making it accessible across different devices.

---

## 🎯 Objectives

- Create a visually appealing and informative tourism website  
- Apply front-end development skills in a real-world project  
- Implement responsive design using Bootstrap  
- Improve user experience through structured content and layout  
- Gain hands-on experience with professional development tools  

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the website  
- **CSS3** – Styling and layout design  
- **Bootstrap** – Responsive design and UI components  
- **Chrome DevTools** – Debugging and optimization  
- **Visual Studio Code** – Code editor
