About Traveller

A dynamic travel guide covering destinations across India.

Traveller helps users discover places from every Indian state and union territory, compare travel moods, and build a saved trip plan from a clean, responsive interface.

Project goal

Designed for a better hiring impression.

The site now behaves like a small product: destination content is stored in one shared JavaScript data source, filters update instantly, route pages render dynamically, and saved places remain available through browser storage.

The visual design uses one earthy green travel theme across every page, with consistent navigation, spacing, card styles, buttons, typography, and footer treatment.

What it shows

Front-end skills made visible.

Dynamic UI

Destination cards, filters, counts, routes, details, and saved trips are controlled with JavaScript state.

Responsive Layout

The interface adapts from large screens to mobile while keeping controls and content readable.

Consistent Design

Every page shares the same travel-inspired palette, typography, buttons, cards, and navigation.
